# Kopi dan Nyemil ☕🍩

## Deskripsi Aplikasi

Kopi dan Nyemil merupakan aplikasi pemesanan kopi dan makanan ringan berbasis Android. Aplikasi ini dirancang untuk memudahkan pengguna dalam melihat pilihan menu, mengelola profil, serta melakukan pemesanan dengan mengisi alamat pengiriman.

Aplikasi ini dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS) mata kuliah Pengembangan Aplikasi Mobile.

## Fitur Aplikasi

1. **Splash / Welcome** – Halaman pembuka aplikasi.
2. **Sign Up** – Pilihan untuk melakukan registrasi atau login.
3. **Login** – Masuk menggunakan akun yang telah terdaftar.
4. **Register** – Membuat akun pengguna baru.
5. **Home** – Menampilkan sapaan pengguna dan lima pilihan produk.
6. **Profile** – Melihat dan mengubah informasi profil pengguna.
7. **Alamat Pengiriman** – Mengisi nama lengkap, alamat, dan detail atau patokan pengiriman.
8. **Konfirmasi Pesanan** – Menampilkan konfirmasi setelah proses pemesanan selesai.

## Teknologi yang Digunakan

- Kotlin
- XML Views
- Android Studio
- ConstraintLayout
- RecyclerView
- SharedPreferences
- Git dan GitHub

## Cara Menjalankan Aplikasi

1. Clone repository:

   ```bash
   git clone https://github.com/USERNAME/Kopi-dan-Nyemil.git
   ```

2. Buka project menggunakan Android Studio.
3. Tunggu proses Gradle Sync selesai.
4. Hubungkan perangkat Android atau jalankan emulator.
5. Klik tombol **Run** untuk menjalankan aplikasi.

## Catatan

- Aplikasi menggunakan data dummy dan penyimpanan lokal.
- Aplikasi tidak menggunakan database maupun backend.
- Seluruh halaman dirancang untuk mendukung alur penggunaan dari pembukaan aplikasi hingga konfirmasi pesanan.
